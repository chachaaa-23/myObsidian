### 3종류 memory
|            | **Static**           | **Stack**           | **Heap**                   |
| ---------- | -------------------- | ------------------- | -------------------------- |
| **주요 활용**  | global 변수, static 변수 | local 변수, parameter | `new` 객체, `*`포인터, `malloc` |
| **관리 주체**  | 컴파일러/OS              | 컴파일러 (자동)           | 프로그래머 (수동)                 |
| **할당 시점**  | 컴파일 타임<br>(크기 일정)    | 런타임 (함수 진입 시)       | 런타임 (`new` 호출 시)           |
| **데이터 수명** | 프로그램 종료 시까지          | 함수 종료 시까지           | `delete` 호출 시까지            |

`new`
- execution time 동안 메모리를 할당할 때 사용
- object 가 저장될 주소의 **pointer** 반환
- heap memory 가 사용 가능하면, 요청된 object or array 를 할당하고, memory 가 할당된 (address of)pointer 반환함

#### `new` vs. `malloc()`
|             | **new (C++)**                   | **malloc() (C)**          |
| ----------- | ------------------------------- | ------------------------- |
| **정체**      | 연산자(Operator)                   | 라이브러리 함수(Function)        |
| **생성자 호출**  | 생성자(Constructor)를 호출하여 객체를 초기화함 | 생성자를 호출하지 않음 (단순 메모리 할당)  |
| **반환 타입**   | 해당 데이터 타입의 포인터를 정확히 반환          | `void*` 타입을 반환 (형변환 필요)   |
| **실패 시 동작** | `bad_alloc` 예외(Exception)를 던짐   | `nullptr` (또는 NULL)을 반환   |
| **오버라이딩**   | 사용자가 동작을 재정의(Overridden) 가능     | 재정의할 수 없음                 |
| **메모리 위치**  | 힙(Heap) 메모리에서 할당                | 힙(Heap) 메모리에서 할당          |
| **크기 계산**   | 컴파일러가 자동으로 계산함                  | 개발자가 직접 바이트 단위 크기를 전달해야 함 |

`NULL` vs. `nullptr`
- `NULL` : int type `0` 
- `nullptr` : std::nullptr_t type
*`NULL` 과 `nullptr`역참조 불가!*
