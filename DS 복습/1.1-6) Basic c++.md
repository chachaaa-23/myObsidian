## C++ basic concept
declaration(선언) and definition can be placed anywhere
	 <-> C: 변수선언, 무조건 블록의 맨 위에 했어야 함

namespace
- 이름 충돌 문제를 해결하기 위한 일종의 울타리. 구분을 위함.
- 특정 식별자(함수, 변수)를 하나의 그룹으로 묶어줌
- `::` Scope resolution operator (범위 지정 연산자)
	1) 같은 이름의 local variable이 있을 때, global variable에 접근-
	2) class 밖에 있는 함수를 정의-
	3) class의 static 변수 접근-
	4) multiple inheritance 시

cin >>
- p) primitive data type 을 input 으로 받을 때엔 유용함
- n) cin 바로 뒤에 std::getline() 바로 쓰면 안됨
	-> cin 입력 후 버퍼에 남아있는 \n 가 getline() 에게 문장이 귾났다고 알려줘서 바로 종료되기 때문.
- n) type-checking x
- n) 공백단위로 끊여서 load 됨(문장 입력 불가)
	-> std::getline() 사용

inline functions
- 기존 c, `macro` 사용.
	preprocessor(전처리기) 의 #define 지시어 사용, 해당 부분 치환해버림.
--> cpp, 평범한 함수처럼 정의됨
- `inline` 키워드를 함수 선언 앞에 입력함. 
- 일반 함수, function call 을 보내면서 값 계산
--> inline, 기계어 코드를 inline 선언 위치에 넣어버림
- n) 과도한 메모리 및 시간 사용 위험 
- p) debugging
- p) type checking
- p) readable
