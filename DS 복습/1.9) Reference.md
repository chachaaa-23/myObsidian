### `&` Reference (참조자)
- 기존 존재하는 변수, 다른 변수에도 alias(별명) 을 붙여주는 것과 같음
- why use?) avoid copying of large structures (함수 파라미터에 `int& x` 와 같이 변수 주소를 넘겨주면 메모리 절약 가능. pointer `*` 사용하는 이유와 비슷)

예시)
```cpp
#include<iostream>
#include<vector>
using namespace std;

int main() {
	vector<int> vec{ 10, 20, 30, 40 };
	
	// auto: 타입 추론 기능. 
	// vec 의 값을 가져다가 제곱해서 for 문 안의 `auto x` 에다가만 저장함. vec 변수의 값은 바뀌지 않음!
	for (auto x: vec) 
//  for (auto &x: vec)   << 참조자 &를 통해 vec 의 주소값에 접근, vec 변수의 값을 직접 변화시킴
		x = x * x;
	
	for (auto x: vec)
		cout << x << " ";
	
	cout << '\n';
	return 0;
}

// Expeced Output: 100 400 900 1600
```

#### `const` reference
=> const 참조
return / pass by reference
- 함수 파라미터로 주소값( & or type* )을 전달하면 메모리가 절약됨 
	(struct 의 경우, struct 주소만 전달하면 4byte 밖에 안됨)
- return by reference 를 통해 값을 할당하는 구문 만들기 가능
	ex) `funcReturnByRef(parm) = 3;`
- 파라미터로 받은 값을 함수 내에서 값을 유지하기 위해 `const` 사용
- *Never return a local variable by reference*
	- runtime error since a local variable does not exist anymore after returned

#### Reference vs Pointer

|             | **포인터 (Pointer)**     | **참조자 (Reference)**                   |
| ----------- | --------------------- | ------------------------------------- |
| **재할당**     | 가능 (언제든 다른 주소 저장)     | **불가능** (초기화 후 고정)                    |
| **NULL 허용** | 가능 (`nullptr`)        | **불가능**                               |
| **역참조 방식**  | `*ptr`, `ptr->member` | `ref`, `ref.member`                   |
| **주요 용도**   | 동적 메모리 할당, 자료구조 구현    | 함수 매개변수 전달, 연산자 오버로딩                  |
| **기타**      |                       | Linked List, Tree 사용 불가 (재할당 불가하기 때문) |
