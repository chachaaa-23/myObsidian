# 선형 구조

#### 🧡1. Array 배열
-- 연속적인 형태의 데이터 구조
-- collection of data of the same type
	- 배열에 포함된 원소, index 가 붙음
	- 고정된 크기. 동적으로 크기 늘리기 x

- p) efficient random **access**
	- constant time O(1)
	- 원소탐색, 찾으려는 원소 index를 알고있으면 : O(1) ~~어디로든 문 열쇠~~
	-> 탐색이 많은 경우 유리 (index 알고있을 때)
	-> fixed data 일 때 유리
- p) locality of reference (지역 참조성) 유리
	- 데이터 순회 시, LL는 지역참조성 low (각각의 데이터들이 흩어져있고 node 로 연결되있기 때문)
	- <-> 주변의 메모리들까지 가져오는 지역 참조성 유리
- n) inefficient insertion and deletion
	- 원소 삭제시, index에 빈자리 생김. 
	- 원소 추가, 삭제시 : O(n) ~~크기가 증가, 새 배열 선언하고 사이즈 n 만큼 옮겨담기~~
	-> 추가, 삭제가 잦은 로직은 불리... ~~계속 옮겨담아?~~

Array 값 가져오기
1) base address:
- list or &list[0]
- first element of array

2) pointer arithmetic:
- `(ptr + 1)`
- 타입 상관없이 array 의 다음 element 를 가리킴 (다음 주소의 element)

3) dereferencing operator:
- `*(ptr + i)`
- `*` 활용, 주소를 통한 역참조
- 배열 안의 내용물 가리킴 (주소에 있는 내용물)

array = &array[0]
`*array` = array[0]
&array = array배열 전체의 주소 (+1 하면 배열 전체를 skip해버림)

#### 2. struct
- organize data in a different type
	- encapsulation of data, a group of data
	- 구조체 정의 시, 원칙적으로 사용할 때 마다 `struct` 붙임
- 무조건 memory `free` 필수! (heap 공간을 할당하기 때문)
```c
struct Car{
	int age;
	char tag[32];
};
struct Car one;
//Car *my = (Car*)malloc(sizeof(Car));
//(*my).age = 20;
```
- `typedef` 를 통해 구조체 이름을 data type 으로 만듬
	- `typedef` 로 구조체 선언 시, 사용할 때마다 `struct` 안붙여도 됨
```c
typedef struct Car{
	int age;
	char tag[32];
};
Car one;
//Car *my = (Car*)malloc(sizeof(Car));
//my->age = 21;
```
--> cpp, `typedef` 없이 data type 으로 만들기 가능
```cpp
struct Car{
	int age;
	char tag[32];
};
Car one;
//Car* my = new Car {20, "mini"};
```

#### 2. Linked List
- 각 요소를 포인터로 연결하여 관리하는 데이터 구조
- 각 요소: Node - 데이터 영역 / 포인터 영역
- 원소 탐색: O(n) ~~내가 찾는 데이터가 맞는지 계속 찾아나서...~~
- 원소 추가, 삭제 : O(1) ~~추가할 위치의 전후 포인터들을 연결한다! ~~
- 종류 : single LL (head - tail 까지 단방향), double LL (head - tail 까지 양방향. 이전과 다음노드 둘다 가리킴. 싱글LL보다 자료구조 크기 조금큼), circular LL
