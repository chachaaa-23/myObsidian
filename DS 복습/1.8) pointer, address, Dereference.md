### `&` Address Operator
=> 주소연산자
- non-array variable 의 주소 얻을 때 사용
예시) `&x` = `x` 의 주소 (3000)

### `*` Dereference Operator
=> 역참조 연산자
- 변수 주소를 타고가서, 그 안의 실제 값 확인/수정
- *실행문* 에 쓰임!
예시) `cout << *p;` p가 가리키는 **주소에 저장된 값** 출력
예시) `*p = 100;` p가 가리키는 주소를 타고가서, 그 위치에 100 값 저장

#### `type *p` Pointer 변수
- 변수값 = 메모리 주소
- *선언문* 에 쓰임!
- **variable** whose **value** is the **address** of a location in memory 
- **value** pointed by pointer variable ptr = `*ptr`

>예시)
>`char str[8] = "Hello";`
>
>- `str` = pointer (bc. **`str`** 의 값이 (배열의 시작)**주소**이기 때문)
>- `str` 은 pointer constant 임 (bc. `str` 선언 시 `char` 으로 선언했기 때문에 주소 할당을 통해 새로운 곳을 가리키게 할 수 없기 때문)
