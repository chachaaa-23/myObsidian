3. 매개변수 전달
- 기본적으로, Call by Value (값에 의한 호출) : actual argument(실인수) 가 formal parameter(형식 매개변수) 로 복사. 
-> 복사작업, 비효율적이고 크고 복잡한 객체라면,,?

 Example)
```cpp
double avg( const vector<int> & arr, int n, bool & errorFlag );
```

	1. Call by constant (ex. arr)
	2. Call by Value (ex. n)
	3. Call by Reference(참조에 의한 호출, ex. errorFlag)

***매개변수 전달(parameter-passing) 매커니즘***
1. formal parameter가 actual argument의 값을 변경할 수 있어야 한다면, Call by reference만 가능. 
2. else, actual argument의 값은 formal parameter를 통하여 변경될 수 없다. 
	- 원시형의 변수를 사용한다면 Call by Value
	- 원시형 변수 사용 x, 클래스 타입의 변수, Call by constant. 

" 포인터 등과 같이 불러온 변수의 값을 실제로 내가 참조하여 변화할 수 있는 경우 / 새롭게 할당된 값이 실인수에 영향을 미치는 경우 = Call by Reference.  "
" 함수의 호출로 그 값이 변하지 않는 경우 = Call by value "

### 3. Value Copy
1. shallow copy (얕은 복사)
: 단순히 동일한 객체를 가리키는 포인터를 저장하는 두 개의 클래스 인스턴스 가지는 것.
2. deep copy (깊은 복사)
: 객체 전체에 대한 복제본 생성. 

### 4. Memory
1. static memory (고정됨! )
- global / static variable live
- compile time 에 할당

2. Heap memory (동적 할당)
- run time 에 dynamically allocated
- memory access를 pointer를 사용해 관리
- new / delete 연산자를 통해 명시적으로 값 할당& 해제

3. Stack memory (지역변수, 매개변수)
- automatic variable에 의해 사용됨
- 함수 entry때 자동으로 생성, 함수의 activation frame 에 reside, 함수로부터 return 받을 때 destroyed.
