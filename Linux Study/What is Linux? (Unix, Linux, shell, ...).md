
## 1. Unix
다양한 종류의 시스템 사이에서 서로 이식가능
multi-tasking, multi-user OS. (멀티태스킹, 다중 사용자 운영체제)

특징:
1) **멀티유저&멀티태스킹** : 한 서버에 여러 사용자가 동시에 로그인해서, 각자 자신의 작업 수행. / 맥북에서 노래 들으면서 gcc 컴파일, 교대로 컴퓨터 자원 사용
2) **모듈화된 구조** : 아주 작고 단순한 기능을 가진 명령어들을 연결하여, 복잡한 작업 수행. 
   ex) ```cat logfile.txt | grep "ERROR" sort | uniq -c```
   (cat: 파일 내용 출력, grep: "ERROR"가 포함된 줄만 추출, uniq -c: 중복제거 + 개수 세기)
3) **터미널 중심** (ls, cd, mkdir, rm, ...)
4) **Everything is a file** : 하드웨어 장치나 프로세스, 네트워크 인터페이스, 프로세스 간 통신 등도 파일처럼 다룰 수 있음. 
5) Portability(이식성) : OS 코드소스가 다양한 하드웨어 아키텍처에서 쉽게 컴파일&실행 가능.

**mount**
- 물리적인 저장장치 (보조기억장치, aka USB) 를 디렉토리에 연결시키는 것. 
- WHY? PnP 기능 부재 (Plug and Play). 디렉토리 연결을 위해 직접 명령 필요. 

**리눅스 프로세스**
- 프로그램: 코딩을 통해 만든 명령어의 집합체.
- 프로세스: 시스템에서 메모리에 적재되어 실행되고 있는 모든 프로그램. 
  프로그램이 실행되는 과정 중에 '현 상황'
  (= 실행되고 있는 프로그램, RAM 에 저장됨.)
	특징
	1) 병행적 실행 가능
	2) 부모(PPID), 자식(Fork 를 통해 복사된 것) 프로세스 있음. 
	   1번 **init 프로세스**: 
	   모든 일반 프로세스의 부모 프로세스. 리눅스 시스템 부팅 시 제일 먼저 실행되는 사용자공간의 프로세스. (자식 프로세스 ex. bash, code, ssh ) 시스템 부팅 및 기본적인 서비스나 데몬 실행. 
	   
	   2번 **kthreadd** **프로세스** (kernel thread demon): 
	   커널 공간에서 실행됨. 커널 내부에서 필요한 **백그라운드** 작업을 하는 **커널 스레드** 생성 (디스크 관리, 메모리 관리, ...) 
	3) kernel 에 의해 관리됨
	4) 프로세스마다 식별을 위한 ID(PIP) 부여.
