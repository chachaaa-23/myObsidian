### 1. AI ruleset detection 과 관련된 3년 이내 연구 찾기

1) ModSec-AdvLearn, Countering Adversarial SQLInjections with Robust Machine Learning
[논문 페이지- 25년 5월](https://arxiv.org/abs/2308.04964)
[오픈소스 github](https://github.com/pralab/modsec-advlearn)

(기존 OWASP CRS, 규칙 집합 결정 시 사용되는 가중치, 수동으로 정의.)

SQLi 공격 탐지 초점,ML 활용해서 결합할 규칙 집합과 가중치 자동으로 선정. 
모니터링되는 web service 기반 CRS 구성 맞춤화. 적대적 학습 (leveraging adversarial training) 활용, 적대적 SQLi 조작 내성 향상.

>	First, we propose using machine learning (ML) to automate both rule selection and weighting, adjusting the CRS configuration based on the traffic data collected from the monitored web services, and building on our preliminary findings in.
>	two linear models, i.e., Support Vector Machines (SVMs) [15] and Logistic Regression (LR) [16], both with ℓ1 and ℓ2 regularization; and a non-linear Random Forest (RF) model

=> 결과: detection rate 최대 30%까지 높힘, 최대 50%의 crs를 설명함. 

ModSec-Learn, Boosting ModSecurity with Machine Learning
(논문 사이트- 24년 6월)[https://arxiv.org/abs/2406.13547]
(오픈소스 코드)[https://github.com/pralab/modsec-learn]
(오픈소스 데이터셋)[https://github.com/pralab/modsec-learn-dataset]

**기존 autoResearch:** AI Agent가 rule을 수정하는 방식
**ModSec Learn:** ML이 rule의 rule weight(중요도)를 학습하는 방식
(SQLi attack 만을 대상으로 함)

### 결과
feature selection with ℓ1(sparse) regularization을 통해 CRS rule의 30% 이상을 제거하면서 성능 유지.

기존 ModSecurity 탐지율(TPR)을 45% 이상 향상. (1% FPR오탐율 기준)

높은 PL(paranoia level)에서도 TRP 향상

### flow
```정적 OWASP CRS 
Request
-> ModSecurity CRS
-> 어떤 Rule이 trigger 되었는지 추출
-> ML Model 입력
-> 최종 분류
```

### scoring
기존 CRS
```
942100 발생
점수 +5

941100 발생
점수 +3
```

ModSec-Learn
1)각각의 **CRS rule** (ex. `Rule 942100`)을 **input feature** vector 로 만든다.
```
Request A

942100 = 1
941100 = 1
932270 = 0
920420 = 0
...
```
2)ML model, 어떤 rule조합이 실제 공격인지 학습.
	`Detection rules, Paranoia, Level, Anomaly Scoring`
3)발생한 공격에 따라 rule의 weight 조정

#### dataset
`legitimate/`, `malicious/` 분리,
`X_train, X_test` 직접 구성 가능함
-> 다양한 tampering script 적용, 탐지 회피형 payload 생성
