# PostgreSQL 서버 설치 및 기본 사용법 정리

## PostgreSQL 설치
### 버전 체계
- **버전 9 이전**: 첫 두 숫자가 주 버전, 세 번째 숫자가 부 버전 (예: 9.6.17)
- **버전 10 이후**: 첫 번째 숫자가 주 버전, 두 번째 숫자가 부 버전 (예: 11.7)
- **부 버전**: 보안 및 안정성 수정만 포함
- **주 버전**: 새로운 기능 추가, 데이터 저장 형식 변경 가능
- **지원 기간**: 주 버전 첫 릴리스부터 5년간 보안 패치 제공

### 설치 과정 (Ubuntu 22.04 기준)
```bash
# 저장소 업데이트
$ sudo apt update

# PostgreSQL 서버 설치
$ sudo apt install postgresql -y
```

**설치 시 자동 생성되는 것들**:
- 첫 번째 클러스터: `14/main`
- PostgreSQL 클라이언트 도구: `postgresql-client-14`
- 시스템 사용자: `postgres`
- 시스템 서비스: `postgresql@14-main.service`, `postgresql.service`

## PostgreSQL 설정
### 설정 파일 위치
```bash
$ less /etc/postgresql/14/main/postgresql.conf
```
**주요 설정 항목**:
- `data_directory`: 데이터 파일 저장 위치
- `hba_file`: 인증 설정 파일 위치
- `listen_addresses`: 네트워크 연결 대기 주소 (기본값: 'localhost')
- `port`: TCP 포트 (기본값: 5432)
- `max_connections`: 최대 연결 수 (기본값: 100)
### 설정 확인 및 변경
```bash
# 전체 설정 확인
$ pg_conftool show all

# 설정 변경
$ sudo pg_conftool set max_connections 101

# 변경 사항 적용 (재시작 필요)
$ sudo systemctl restart postgresql
```

### 프롬프트 의미

| 끝에서 두 번째 문자   | 의미                  |
| ------------- | ------------------- |
| `=`           | 명령 대기 중 (정상 모드)     |
| `-`           | 이전 명령이 `;`로 종료되지 않음 |
| `^`           | 단일 라인 모드            |
| `!`           | 데이터베이스 연결 끊김        |
| `*`           | 미완료 주석 (`/*`)       |
| `'`, `"`, `$` | 미완료 인용              |
| `(`           | 미완료 괄호              |

### 🧡명령 입력 규칙

1. **SQL 명령**: 세미콜론(`;`)으로 종료
2. ==🩵**psql 내부 명령**: 백슬래시(`\`)로 시작==
3. **명령 취소**: `Ctrl+C`

**한 줄에 하나의 명령**:

```sql
postgres=# SELECT current_database(), current_user;
```

**한 줄에 여러 명령**:

```sql
postgres=# SELECT current_database(); SELECT current_user;
```

**여러 줄에 하나의 명령**:

```sql
postgres=# SELECT current_database(
postgres(# ), current_user
postgres-# ;
```

### 대소문자 규칙

**따옴표 없는 경우**: 자동으로 소문자 변환

```sql
Select * From Person;
SELECT * FROM PERSON;
SELECT * FROM person;
-- 모두 동일하게 처리됨
```

**따옴표 있는 경우**: 대소문자 유지

```sql
select * from "Person";  -- "Person" 테이블 찾음
select * from person;     -- "person" 테이블 찾음 (다른 테이블!)
```

- 컬럼명, 테이블명 작성 시

## 🩵데이터 검색

### [LIKE](https://www.postgresql.org/docs/14/functions-matching.html#FUNCTIONS-LIKE) 연산자
- `%`: 0개 이상의 모든 문자
- `_`: 정확히 1개의 문자

```sql
SELECT *
FROM pet 
WHERE name LIKE '%e_';
```

**와일드카드**:
- `%`: 0개 이상의 임의 문자
- `_`: 정확히 1개의 임의 문자

### [POSIX](https://www.postgresql.org/docs/14/functions-matching.html#FUNCTIONS-POSIX-REGEXP) 정규표현식 (`~`)

```sql
SELECT *
FROM pet 
WHERE name ~ '^.*(g|s)$';
```

| **기호**   | **의미**              | 예시          | 설명                      |
| -------- | ------------------- | ----------- | ----------------------- |
| **`^`**  | 문자열의 **시작**         | `'^A'`      | 'A'로 시작하는 데이터           |
| **`$`**  | 문자열의 **끝**          | `'A$'`      | 'A'로 끝나는 데이터            |
| **`.`**  | **아무 문자나 1개**       | `'A.C'`     | ABC, ADC, A1C 등         |
| **`[]`** | 괄호 안의 문자 중 **하나**   | `'[nw]A'`   | 'nA' 또는 'wA'            |
| **`*`**  | 앞의 문자가 **0번 이상** 반복 | `'ab*'`     | a, ab, abb, abbb 등      |
| **`+`**  | 앞의 문자가 **1번 이상** 반복 | `'ab+'`     | ab, abb, abbb 등 (a는 안됨) |
| **`      | `**                 | **OR (또는)** | `'A                     |
### SIMILAR TO 연산자

```sql
SELECT *
FROM pet 
WHERE name SIMILAR TO '%(l|p)_';
```

## 인코딩과 콜레이션(Collation)

### 개념

- **문자 집합(Character Set)**: 문자를 저장하는 방식
- **콜레이션(Collation)**: 문자를 비교하고 정렬하는 방법

### 설정 가능 범위

- **문자 집합**: 클러스터 또는 데이터베이스
- **콜레이션**: 클러스터, 데이터베이스, 컬럼, SQL 쿼리

### 로케일 설정

**사용 가능한 로케일 확인**:

```bash
$ locale -a
```

**한국어 로케일 생성**:

```bash
$ sudo locale-gen pl_PL pl_PL.UTF-8

# PostgreSQL 재시작
$ sudo systemctl restart postgresql
```

### 인코딩을 지정한 데이터베이스 생성

```sql
-- LATIN2 인코딩
CREATE DATABASE polish_latin2
WITH ENCODING 'LATIN2'
LC_COLLATE 'pl_PL'
LC_CTYPE 'pl_PL'
TEMPLATE template0;

-- UTF-8 인코딩
CREATE DATABASE polish_utf8
WITH ENCODING 'UTF-8'
LC_COLLATE 'pl_PL.UTF-8'
LC_CTYPE 'pl_PL.UTF-8'
TEMPLATE template0;
```

### 콜레이션 생성

```sql
\c polish_utf8

CREATE COLLATION "pl_PL.utf8" (locale = "pl_PL.UTF-8");
```

### 콜레이션 목록 확인

```sql
SELECT * FROM pg_collation;
```

**ICU 콜레이션**: `collprovider` 열이 `i`이고 이름이 `-icu`로 끝남

### 🩵테이블 생성 시 콜레이션 지정
#### 🍎*==컬럼 이름== 입력 시 ==큰따옴표`"` !*==

```sql
CREATE TABLE names                                     
(
  fr TEXT COLLATE "fr-FR-x-icu", -- fr = col_name
  pl TEXT COLLATE "pl_PL.utf8" -- 🩵collation 이름, 큰따옴표로 감싸야함
);
```

**확인**:

```sql
\d names
```

```
               Table "public.names"
 Column | Type |  Collation  | Nullable | Default 
--------+------+-------------+----------+---------
 fr     | text | fr-FR-x-icu |          | 
 pl     | text | pl_PL.utf8  |          | 
```

### 🩵데이터 입력 및 비교
#### 🍎*==데이터 값== 입력 시  ==작은따옴표`'` !*==
```sql
INSERT INTO names VALUES 
('Boris', 'Borys'),
('Bernard', 'Bernard'),
('Béatrice', 'Beatrycze');

-- 서로 다른 콜레이션 비교 시 오류 발생
SELECT fr < pl
FROM names;
-- ERROR: could not determine which collation to use

-- 쿼리에서 콜레이션 명시
SELECT fr < pl
COLLATE "pl_PL.utf8"
FROM names;
```

### 정렬 비교

**컬럼 콜레이션(컬럼 정렬) 사용**:

```sql
SELECT fr 
FROM names 
ORDER BY fr;
```

```
 Béatrice
 Bernard
 Boris
```

🩵**쿼리에서 C 콜레이션 사용** (바이트 비교):

```sql
SELECT fr -- col
FROM names -- table
ORDER BY fr -- 정렬할 대상 column
COLLATE "C"; -- 정렬에 사용할 collate
```

```
 Bernard
 Boris
 Béatrice
```

### 🩵컬럼 콜레이션 변경

```sql
ALTER TABLE names
ALTER COLUMN fr
SET DATA TYPE text 
COLLATE "pl_PL.utf8";
```

## 🩵주요 psql 명령어 요약
- *psql 접속 중, 다른 user로 접속*
	`\c [db_name] [login_user_name]`

- 특정 DB 정보 확인
	`\list db_name`

| `\l`, `\list`            | 데이터베이스 목록      |
| ------------------------ | -------------- |
| `\c DB명`, `\connect DB명` | ==데이터베이스 전환==  |
| `\dt`                    | 테이블 목록         |
| `\d 테이블명`                | 테이블 구조 확인      |
| `\t`                     | 열 이름/행 수 표시 토글 |
| `\q`                     | psql 종료        |
| `help`                   | 도움말            |




## 핵심 정리

1. **설치**: `apt install postgresql` - 클러스터, 사용자, 서비스 자동 생성
2. **접속**: `sudo -u postgres psql`
3. **명령**: SQL은 `;`로 종료, psql 명령은 `\`로 시작
4. **대소문자**: 따옴표 없으면 소문자 변환, 있으면 유지
5. **클러스터**: 함께 관리되는 데이터베이스 그룹
6. **기본 DB**: postgres, template1, template0
7. **콜레이션**: 클러스터/DB/컬럼/쿼리 레벨에서 설정 가능
