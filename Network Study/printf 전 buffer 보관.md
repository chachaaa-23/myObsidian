printf, 실행중인 프로그램의 출력 버퍼에 쌓아뒀다가 특정 조건 때 출력함. 

터미널(콘솔) 출력 환경에서 `stdout`, 기본적으로 행 버퍼링(Line Buffering) 방식으로 동작함
*행 버퍼링, 아래 조건에서만 버퍼에 쌓인 내용을 화면에 flush 함:*
	1. `\n` 만날 때
	2. 출력버퍼 꽉 찼을 때
	3. `scanf` 등으로 입력 기다려야 할 때
	4. 프로그램이 정상적으로 종료될 때

버퍼 강제로 비우고 싶을 때, 
	`fflush(stdout)` 사용.
