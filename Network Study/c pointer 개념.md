[[>Computer network]]

pkt_t 포인터 타입을 UDP 통신으로 전송할 때, `sizeof(pkt_t*)`
와 같이 "포인터 변수" 만큼 공간 선언 필요! (!=  구조체 변수의 크기 )


---

`int three = 3;`
`int* num = &three;`

| **표현식** | **의미**                                          | **예시 결과**            |
| ------- | ----------------------------------------------- | -------------------- |
| `*num`  | 가리키는 곳에 들어있는 **실제 값**                           | `3`                  |
| `num`   | 가리키는 곳의 **메모리 주소** (three 의 주소)                 | `0x1000` (임의의 주소)    |
| `&num`  | 포인터 변수 본인의 **메모리 주소** (int* num 이라는 포인터 변수의 주소) | `0x2000` (임의의 다른 주소) |
